# Website Builder

Créateur de sites Internet sans code : on assemble des blocs (titres, textes, images, galeries, colonnes, formulaire, carte…), on personnalise les couleurs et les polices, puis on exporte le site en ZIP prêt à publier.

## Utilisation

Ouvrez `index.html` dans un navigateur, ou utilisez la version en ligne via GitHub Pages.

- Éditeur en trois zones : blocs et structure à gauche, aperçu au centre, réglages à droite
- Glisser-déposer, annuler/rétablir, aperçu ordinateur / tablette / mobile
- Plusieurs pages avec menu automatique
- Sauvegarde automatique dans le navigateur
- Export ZIP : HTML, CSS, JS et images, hébergeable sur Netlify, GitHub Pages ou un hébergement classique

Les projets sont enregistrés dans le navigateur de chaque utilisateur. Pensez à exporter une sauvegarde `.json` depuis le bouton Exporter.

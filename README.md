# Website Builder

Créateur de sites Internet sans code : on assemble des blocs, on personnalise le design, puis on exporte un site prêt à publier.

**Utiliser en ligne :** https://dzjdhadbdroid.github.io/website-builder/

## Fonctionnalités

- Éditeur en trois zones : blocs, structure et pages à gauche, aperçu au centre, réglages à droite
- Blocs : titre, texte, image, vidéo, galerie, citation, boutons, liens, réseaux sociaux, colonnes, section pleine largeur, formulaire, carte, menu, pied de page…
- Modification des textes directement dans l'aperçu, glisser-déposer, annuler/rétablir
- Design du site : palettes, polices (import de vos propres polices), formes de boutons, couleurs
- Images : formes, contours, dimensions, cadrage et zoom (aussi dans la galerie)
- Plusieurs pages avec menu automatique, modèles de pages (À propos, Contact, Galerie, Tarifs, FAQ, Mentions légales)
- Aperçu ordinateur / tablette / mobile, avec des réglages propres à chaque appareil
- Mode libre : placement libre des blocs sur toute la page (premier plan / arrière-plan)
- Visite guidée de l'éditeur (bouton ?)
- Export ZIP : HTML, CSS, JS, images et polices, hébergeable sur GitHub Pages, Netlify ou un hébergement classique

## Remarques

- Les projets sont enregistrés dans le navigateur de chaque utilisateur (rien n'est envoyé sur un serveur). Pensez à enregistrer une sauvegarde `.json` pour garder ou transférer un projet.
- Si une mise à jour n'apparaît pas, rechargez avec Ctrl+Maj+R.
- Vérifiez que les polices importées sont libres de droits pour un usage web.
